HANNAN PORTFOLIO
================

Files:
- index.html  = website content
- style.css   = design
- script.js   = menu + year

TO CUSTOMIZE:
1. Open index.html.
2. Change "Hannan" to your preferred display name if needed.
3. Edit the About section.
4. Replace the five sample project cards with your real projects.
5. Replace # links with your real GitHub/LinkedIn/demo links.
6. Change your@email.com to a public email you are comfortable sharing.

TO TEST:
Open index.html in Chrome.

TO PUBLISH:
A simple free option is GitHub Pages. Create a GitHub repository, upload these files, enable Pages, and GitHub will give you a public website address.
